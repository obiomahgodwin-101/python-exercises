\# Python Exercises



This repository contains beginner-friendly Python exercises.



\## Exercise 1: Calculator Module

\- `calculator.py`: Contains functions for addition, subtraction, multiplication, and division.

\- `main.py`: Uses the calculator module to perform operations on numbers (example: 5 and 3).



\## Exercise 2: Weather Script

\- `weather.py`: Uses the `requests` library to fetch weather data from the OpenWeatherMap API.

\- Replace `API\_KEY` in the script with your own key from \[OpenWeatherMap](https://openweathermap.org/api).
